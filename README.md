# Axel Portfolio

Personal portfolio website of Russel Orion Exelent De Misbach (Axel) — Web Developer & Programming Instructor from Sidoarjo, Indonesia.

A remake of the [lurais](https://lurais.framer.website/) portfolio: same layout, features, concept and uniqueness, with Axel's own content and photos. Built together with Gemini. Rebuild v2 (21 Nov 2026) follows a full audit of the reference: elegant monochrome palette, bracket-style buttons (no fill), no photo hover effects, no parallax, slot-rotating /WORKED WITH marquee, auto-sliding testimonial rail with edge fade, letter-reveal headings, and a world clock covering all 195 countries (hero 12-hour + Principle 5 24-hour, one selectable time zone).

## Live site

https://orionrusel-rgb.github.io/axel-portfolio/

## Structure

- `index.html` — hero with world clock, worked-with slots, introduction, best works, principles, portfolio, about, services, experience, testimonials, FAQ, contact footer
- `style.css` — design system, responsive breakpoints (desktop ≥1200px / tablet 810–1199px / phone ≤809px)
- `script.js` — world clocks (195 countries), menu, slot rotation, count-up stats, testimonial rail, letter reveal, FAQ toggles
